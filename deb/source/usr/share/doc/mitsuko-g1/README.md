# Mitsuko G1 Light Sync for Linux

A desktop controller for the Mitsuko Phantom G1 monitor light strip. It provides USB control, screen-edge lighting, music-reactive modes, and the effects exposed by the device firmware.

The Linux controller communicates with the strip over USB HID (`1a86:fe07`). Its protocol was derived from the Windows application; this is an independent community implementation, not an official Mitsuko Linux app.

## Install

Install the Debian package and its declared system dependencies:

```bash
sudo apt install ./mitsuko-g1.deb
```

Launch **Mitsuko G1 Light Sync** from the applications menu or run:

```bash
mitsuko-g1
```

The package installs and reloads the USB udev rule. Reconnect the strip if it was already plugged in. It also adds the installing account to `plugdev` when installed through `sudo`; log out and back in if needed for that group change to take effect.

## Features

The GUI is organized into four sections: Music reactive, Screen sync, Lighting effects, and Quick controls. Its music view shows a monitor-perimeter map alongside the active mode and sensitivity controls.

### Background behavior

Closing the window hides it while Mitsuko G1 keeps running. Use the **Mitsuko G1** indicator in the GNOME top panel to reopen the window or quit the application. **Ctrl+Q** also quits; if a live LED mode is running, the app asks before stopping it.

### Screen sync

Samples colors near the edges of the monitor and maps them around the strip. The GUI lets you set the LED count, the number of LEDs assigned to each edge, target FPS, smoothing, and edge sampling depth.

The package includes the Wayland portal capture helper and the X11 `mss` capture module. On first use in Wayland, authorize monitor capture once:

```bash
wayland-screenshot cast enroll --monitor
```

This opens the desktop portal permission chooser. Screen sync can then reuse the saved permission. Music sync does not need screen capture permission.

### Live music

Captures the computer's PipeWire playback mix, so no microphone is needed. Select a mode and adjust sensitivity in the GUI:

- **Combined:** bass pulses along the bottom; vocal-range and midrange energy colors the sides; treble accents the top.
- **Bass:** reacts mainly to low-frequency energy and beat changes.
- **Treble:** emphasizes high-frequency energy and transients.
- **Voice emphasis:** emphasizes energy in a vocal-like frequency range. It does not isolate or identify vocals.

Combined mode uses the current perimeter counts in the GUI. The selected color anchors its palette. Press **Stop live mode** to stop music capture and LED updates.

### Lighting effects and controls

- **Dynamic 1–7:** built-in firmware effects.
- **Pickup 1–7:** built-in sound-reactive firmware effects.
- **Color Flow, Aurora, Breathe, Comet, Ember:** effects generated by the app and streamed to the strip.
- **Quick controls:** choose a solid color, set brightness, or turn the LEDs off.

## Settings

Per-user settings are stored in:

```text
~/.config/mitsuko-g1/
```

The GUI saves the LED count, edge counts, screen-sync settings, brightness, music mode, and audio sensitivity there.

## Command line

The package also installs `mitsuko-g1ctl` for device commands. For example:

```bash
mitsuko-g1ctl info
mitsuko-g1ctl off
mitsuko-g1ctl brightness 128
```

Run `mitsuko-g1ctl --help` for controller options and `mitsuko-g1ctl music --help` for music-mode options.

## Dependencies and permissions

The package manager installs the Python HID, NumPy, Tk, D-Bus, GStreamer, PipeWire, and desktop-portal dependencies. The package also installs the USB udev rule. Wayland monitor capture still requires the one-time portal permission described above; this authorization is a desktop security prompt and cannot be pre-granted by installing a package.

Actual LED update speed can vary with the display-capture path and USB device pacing.

## Android phone companion

The companion app can control the G1 over USB debugging or over the same local Wi-Fi network. Open Mitsuko G1 on the laptop, choose **Phone Wi-Fi setup**, then enter the displayed laptop address and pairing code in the Android app. After the initial pairing, the phone remembers its access token and automatically discovers the laptop on the same Wi-Fi network, so reconnects need no IP or code. USB remains a fallback. The relay limits phone control to paired devices on the local network.
