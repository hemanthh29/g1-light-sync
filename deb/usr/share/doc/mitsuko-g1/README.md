# G1 Light Sync for Linux

An unofficial desktop controller for the Mitsuko Phantom G1 monitor light strip. G1 Light Sync is an independent project, not affiliated with or endorsed by Mitsuko. It provides USB control, screen-edge lighting, music-reactive modes, and the effects exposed by the device firmware.

The Linux controller communicates with the strip over USB HID (`1a86:fe07`). Its protocol was derived from the Windows application.

## Install

Install the Debian package and its declared system dependencies:

```bash
sudo apt install ./mitsuko-g1.deb
```

Launch **G1 Light Sync** from the applications menu or run:

```bash
mitsuko-g1
```

The package installs and reloads the USB udev rule. Reconnect the strip if it was already plugged in. It also adds the installing account to `plugdev` when installed through `sudo`; log out and back in if needed for that group change to take effect.

## Features

The GUI is organized into four sections: Music reactive, Screen sync, Lighting effects, and Quick controls. Its music view shows a monitor-perimeter map alongside the active mode and sensitivity controls. Scroll the main content with the mouse wheel or the scrollbar to reach controls below the visible area.

### Background behavior

Closing the window hides it while G1 Light Sync keeps running. Use the **G1 Light Sync** indicator in the GNOME top panel to reopen the window or quit the application. **Ctrl+Q** also quits; if a live LED mode is running, the app asks before stopping it.

### Phone Wi-Fi relay

The **Phone Wi-Fi setup** window shows the laptop address and pairing code and includes a relay switch. Turning it on enables the per-user systemd service at desktop login; the relay continues running after G1 Light Sync closes. Turning it off stops the service and prevents it from starting at the next login.

### Screen sync

Samples colors near the edges of the monitor and maps them around the strip. The GUI lets you set the LED count, the number of LEDs assigned to each edge, target FPS, smoothing, and edge sampling depth.

The package includes the Wayland portal capture helper and the X11 `mss` capture module. On first use in Wayland, authorize monitor capture once:

```bash
wayland-screenshot cast enroll --monitor
```

This opens the desktop portal permission chooser. Screen sync can then reuse the saved permission. Music sync does not need screen capture permission.

### Live music

Captures the computer's PipeWire playback mix, so no microphone is needed. Select a mode and adjust sensitivity in the GUI:

- **Combined:** the song's overall loudness changes brightness across the strip; bass activity and kick hits drive the bottom; midrange activity shapes the sides; treble transients accent the top. These signals are analyzed together and rendered as separate layers in each frame. Choose and save a separate color for each zone in the Music zone colors card.
- **Bass:** reacts mainly to low-frequency energy and beat changes.
- **Treble:** emphasizes high-frequency energy and transients.
- **Voice emphasis:** emphasizes energy in a vocal-like frequency range. It does not isolate or identify vocals.

Combined mode uses the current perimeter counts in the GUI. Zone colors are saved with the desktop preferences and are used in combined and single-zone modes. Starting another live mode while one is active stops the current mode and switches to the selected one; the start controls remain available.

### Lighting effects and controls

- **Dynamic 1–7:** built-in firmware effects.
- **Pickup 1–7:** built-in sound-reactive firmware effects.
- **Color Flow, Aurora, Breathe, Comet, Ember:** effects generated by the app and streamed to the strip.
- **Solid color:** choose a preset or custom color in the Lighting effects section, then apply it to the strip.
- **Quick controls:** adjust brightness or turn the LEDs off. The notification card offers single pop, double pulse, soft breathe, perimeter ping, and urgent triple patterns with a custom alert color and a preview button. Notification patterns are available only for solid-color and off states; they skip built-in/app lighting effects and screen or music sync, and restore the prior steady state afterward.

## Settings

Per-user settings are stored in:

```text
~/.config/mitsuko-g1/
```

The GUI saves the LED count, edge counts, screen-sync settings, brightness, music mode, audio sensitivity, music-zone colors, and notification pattern/color preferences there.

## Command line

The package also installs `mitsuko-g1ctl` for device commands. For example:

```bash
mitsuko-g1ctl info
mitsuko-g1ctl off
mitsuko-g1ctl brightness 128
```

Run `mitsuko-g1ctl --help` for controller options and `mitsuko-g1ctl music --help` for music-mode options.

## Dependencies and permissions

The package manager installs the Python HID, NumPy, Tk, D-Bus, GStreamer, PipeWire, and desktop-portal dependencies. The package also installs the USB udev rule. Wayland monitor capture still requires the one-time portal permission described above; this authorization is a desktop security prompt and cannot be pre-granted by installing a package.

Actual LED update speed can vary with the display-capture path and USB device pacing.

## Android phone companion

The companion apps can control the G1 over USB debugging or over the same local Wi-Fi network. Open G1 Light Sync on the laptop, choose **Phone Wi-Fi setup**, then pair the phone using the displayed code. After the initial pairing, the phone remembers its access token and automatically discovers the laptop on the same Wi-Fi network, so reconnects need no IP or code. USB remains a fallback for Android. The relay limits phone control to paired devices on the local network.
